# 停用模块

这个目录里的文件**不参与编译**（`scripts/build.tcl` 只收 `rtl/*.v`），
留在这里只是为了让后来看代码的人知道它们曾经存在、为什么被换掉。

## alarm_ctrl.v

第一阶段（v1）的报警模块：三档 LED 电平柱 + 连续 4 帧超阈就蜂鸣。

换掉的原因：它只比"这一帧响不响"，风噪、说话、关门、吹风机全会触发，
2048 个样本里能刷出十几次假报警。v2 起改用 `rtl/snore_judge.v`
的三条件判据（响度包络 + 持续时间 + 节律间隔），
`snore_top.v` 里已经不再例化它。

如果只是想看"当前这一帧响不响"，`snore_judge` 的 `status[0]`
和 LED0 提供的信息是一样的，不需要把它请回来。
